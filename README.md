
# Eurovision Fairytale 2009

A tribute website inspired by Alexander Rybak's
unforgettable Eurovision 2009 performance.

## Features

- Alexander Rybak photo
- Eurovision-inspired dark blue and gold design
- MY INSPIRED NOTES section
- Play and Stop music buttons
- Responsive mobile-friendly layout

## Technologies

- HTML
- CSS
- JavaScript
- Web Audio API
